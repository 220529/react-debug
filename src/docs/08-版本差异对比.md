# React 版本差异对比

## 版本信息

| 项目 | react-debug (当前) | react (新 clone) |
|------|-------------------|------------------|
| 版本 | 19.0.0 | 19.3.0 |
| 来源 | 本地调试项目 | GitHub 最新 |

## 新增特性 (19.3.0)

### 1. Activity 组件（原 Offscreen）

```javascript
// 19.0.0
REACT_OFFSCREEN_TYPE as unstable_Activity

// 19.3.0
REACT_ACTIVITY_TYPE as Activity  // 正式 API
```

Activity 用于离屏渲染和预渲染，可以在后台准备 UI：

```jsx
import { Activity } from 'react';

<Activity mode="hidden">
  <HeavyComponent />
</Activity>
```

### 2. ViewTransition 组件（新增）

```javascript
// 19.3.0 新增
REACT_VIEW_TRANSITION_TYPE as ViewTransition
```

用于页面过渡动画，基于浏览器的 View Transitions API：

```jsx
import { ViewTransition } from 'react';

<ViewTransition>
  <PageContent />
</ViewTransition>
```

### 3. Gesture Transition（新增）

```javascript
// 19.3.0 新增
startGestureTransition as unstable_startGestureTransition
```

支持手势驱动的过渡动画。

### 4. cacheSignal（新增）

```javascript
// 19.3.0 新增
import { cacheSignal } from 'react';
```

用于缓存信号管理。

### 5. addTransitionType（新增）

```javascript
// 19.3.0 新增
import { addTransitionType } from 'react';
```

用于添加过渡类型标识。

### 6. optimisticKey（新增）

```javascript
// 19.3.0 新增
REACT_OPTIMISTIC_KEY as optimisticKey
```

用于乐观更新的 key 标识。

## WorkTags 变化

```javascript
// 19.0.0 (29 种)
export const Throw = 29;

// 19.3.0 (31 种，新增 2 种)
export const Throw = 29;
export const ViewTransitionComponent = 30;  // 新增
export const ActivityComponent = 31;        // 新增
```

## API 导出变化

### 19.0.0 导出

```javascript
export {
  // ...
  REACT_OFFSCREEN_TYPE as unstable_Activity,
  useEffectEvent as experimental_useEffectEvent,
  REACT_DEBUG_TRACING_MODE_TYPE as unstable_DebugTracingMode,
  // ...
}
```

### 19.3.0 导出

```javascript
export {
  // ...
  REACT_ACTIVITY_TYPE as Activity,           // 稳定 API
  useEffectEvent,                            // 移除 experimental 前缀
  ViewTransition,                            // 新增
  addTransitionType,                         // 新增
  startGestureTransition as unstable_startGestureTransition,  // 新增
  optimisticKey,                             // 新增
  cacheSignal,                               // 新增
  // 移除了 unstable_DebugTracingMode
}
```

## 新增 packages

```
19.3.0 新增：
├── react-server-dom-parcel/     # Parcel 打包器支持
└── react-server-dom-unbundled/  # 无打包器支持
```

## Feature Flags 变化

```javascript
// 19.3.0 新增的 Feature Flags
export const enableViewTransition: boolean = true;
export const enableGestureTransition = __EXPERIMENTAL__;
export const enableScrollEndPolyfill: boolean = true;
export const enableThrottledScheduling: boolean = false;
export const enableOptimisticKey: boolean = true;
```

## 总结

| 变化类型 | 内容 |
|---------|------|
| 稳定化 | Activity (原 unstable_Activity)、useEffectEvent |
| 新组件 | ViewTransition |
| 新 API | cacheSignal、addTransitionType、startGestureTransition、optimisticKey |
| 新 WorkTag | ViewTransitionComponent (30)、ActivityComponent (31) |
| 移除 | unstable_DebugTracingMode |

**建议**：当前 19.0.0 版本足够学习核心原理，19.3.0 主要是新增了 View Transitions 相关特性，核心架构（Fiber、Scheduler、Reconciler）没有本质变化。
